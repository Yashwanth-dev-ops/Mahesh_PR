# Roadmap

Phases and their detail: PLAN_V2.md §5. Status as of 2026-11-25.

## DONE (class pilot so far)
Roll-number + Google sign-in, sign-up against the class roster, admin approval · Home, subjects, chapters (notes, files, important questions), PDF reader with resume, progress, search · Question papers with filters · Notices with categories · Admin dashboard (roster CSV, approvals, notices, stats, feedback) · Backup/restore scripts · PDF and photo compression

## NOW (before the pilot exam)
Import the class's real content and roster · Email service for password resets (Resend) · Login rate limit · Exam mode · Deploy (when the owner says)

## NEXT (during the pilot)
Notice bell + pop-up + targeting · Save chapters offline · Audit log

## AFTER THE PILOT
Student uploads + near-duplicate check + review queue + points · Quizzes, spaced-repetition flashcards, mastery · Chapter discussion · Subject/chapter editor, PDF → chapter converter (OCR) · Ads (college approval first) · Move files to Cloudflare R2

## LATER (phase 2)
- **AI study assistant:** chapter Q&A and summaries from approved material (needs a cost plan, since each answer costs money)
- **Practice lab:** in-browser Python runner (Pyodide, no server cost) first, then C/Java/shell through a sandboxed execution service, with exercises linked to chapters and picked by the student's interests
- Other branches · Sponsored notice slots · Leaderboard / contributor badges

## NOT PLANNED
Native apps · Payments/premium · Direct messages
